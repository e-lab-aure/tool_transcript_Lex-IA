Utiliser LEX-IA

Transcrire

Collez le lien d’une vidéo ou choisissez un fichier, puis lancez la transcription.

Reconnaître les voix

Pour un entretien à deux, cochez « Distinguer les personnes qui parlent » et indiquez un nombre exact de 2. Vous pourrez ajuster les voix dans le lecteur.

Relire et exporter

Dans le lecteur, cliquez sur un repère de temps pour écouter et sur le texte pour le corriger. Choisissez TXT pour un texte ou SRT pour des sous-titres.

Conserver le résultat

Exportez vos corrections avant de recharger la page. Les fichiers préparés par le serveur expirent après 24 heures.
